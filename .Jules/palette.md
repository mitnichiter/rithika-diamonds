## 2025-05-14 - Interactive Utility & Semantic Navigation
**Learning:** In luxury brand websites, utility bars (TopBar) often prioritize aesthetics over functionality, but converting static contact info into interactive `tel:` and map links significantly improves mobile usability without compromising design. Additionally, using semantic `<button>` elements for custom slider dots with `aria-label` is a critical low-effort/high-impact accessibility win.
**Action:** Always check if contact information is actionable and ensure custom navigation elements (like slider dots) use semantic HTML and ARIA labels.

## 2025-05-14 - Newsletter Form Feedback
**Learning:** A "Subscribing..." loading state and success message for newsletter forms provides essential feedback that prevents multiple submissions and confirms the user's action, which is especially important for high-end brands where the user expects a polished, responsive experience.
**Action:** Implement `isSubmitting` states and success notifications for all form-based interactions.
